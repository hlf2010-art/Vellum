What the composer offers after `/` (moves) or `@` (crew).

Taken from `.menu` in `Vellum-Lumen.html`.

- Each row has the crew orb that will do the move (or a quiet dot for board moves), the command in 600/14, and a one-line description.
- A hint such as `2–4` follows the command in `label-3`.
- ↑ ↓ move, Enter picks, and hover sets the active row. The active row has a `hover` fill; there are no dividers.
