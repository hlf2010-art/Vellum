Actions for one selected card, floating just above it: one solid pill.

For two or more cards use `SelectionBar`. Since 27 Nov, bars that float over cards are solid `card`, never glass, so the words under them never show through.

- Groups are separated by **space** (10px), not by vertical bars.
- Use text buttons for the card's own moves (*Explore*, *Build proof*, *Adopt*), and icon-only buttons for generic actions (Duplicate, Lock, Delete), each with a tooltip that includes its shortcut.
- A lineage action takes the lineage ink. Delete takes `danger-ink`.
- No count label and no coloured crew orbs: the selection ring already says what is selected.
- Keep it to one row: at most 6 items.
