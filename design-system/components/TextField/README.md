A filled input well (`card-2`) with its label above and help or an error below.

- 16px text, so iOS doesn't zoom.
- Focus is a 2.5px `focus` ring.
- An error tints the well, turns the help line `danger-ink` with an alert icon, and says how to fix it.
- Mark the rare optional field *optional*. Don't mark required fields.
- `multiline` gives a textarea.
