How cards connect on the board: a soft cubic curve from an out-port to an in-port, ending in a small dot.

- Neutral wires use `thread`. Lineage wires use `A-fill`…`D-fill` (a wire is a mark, not text).
- `state`: `hover` thickens it, `reference` dashes it (a reference link with no update alerts), `stale` turns it `warn` and dashes it (the source changed).
- Wires stay under cards (`z-wire`).
