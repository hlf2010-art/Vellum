For a setting that takes effect at once (*Reduce transparency*). The label and its help sit on the left, the switch on the right.

- On is `ok-fill` (leaf green). Off is a light 16% `label` track; the white thumb, lifted by its shadow, shows the state by its position, so the control never depends on colour. The app's settings switches use the same colours.
- Don't use a switch for something that needs a Save button.
