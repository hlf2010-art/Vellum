The A–D letter that ties a card, wire or proposal to its direction.

Hand-written from `.chip` in `Vellum-Lumen.html` (branch `claude/lumen-v2`). The fill is the lineage token (`A` amber, `B` blue, `C` green, `D` rose) and the letter is `chip-ink`. It is 18px square with `radius-chip` and set in `chip` type. `size="lg"` (24px) is for headers and popovers. `selected` adds a ring in the chip's own hue, e.g. for the active lineage filter.

Use the chip wherever a direction is named: the card head, toasts, review lists. Always pair it with the word “Direction” or the title the first time. Light-theme white on `A` and `C` is below 4.5:1 (a source value, flagged in tokens), and the letter is never the only cue.
