How much evidence a card rests on, as **one block per source**. Above 16 sources it becomes a proportional bar.

- Each block uses the lineage *mark* tokens (`C-mark` observed, `A-mark` reported, `B-mark` proposal, `press` unrated), never the text inks.
- The caption is plain words: *“Evidence behind it · 4 observed · 1 reported”*. Don't use “Evidence mix”.
- The tooltip explains that sources behind linked directions and questions count too.
- Two sources must look like two blocks, not like a finished progress bar.
