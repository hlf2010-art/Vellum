The Vellum app mark: `vellum-mark.svg`. It is a #16171B rounded tile (rx 6.6 on a 24 grid) with a white beam entering a prism and leaving as four rays in the dark lineage colours (#FFB547, #5AA2FF, #45D49A, #FF6B95). Copied from the app's favicon.

Use it at 16–96px for the app icon, favicon and the about screen. It is self-coloured, so it works on both themes. Never recolour it, never separate the prism from the tile, and never set the word “Vellum” beside it as a lockup. Vellum has no wordmark; set the name in Inter 600 when needed.
