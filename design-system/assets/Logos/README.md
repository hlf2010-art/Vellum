The app mark: `vellum-mark.svg`, the same drawing as the Dock icon (`studio/macos-app/brand/sympo-icon.svg`). A dark rounded tile (rx 22.5 on a 100 grid) holding a five-faced stone. One face is white: the decision. The other four carry the direction colours as one continuous band (yellow, green, blue, violet, rose, amber), and every colour lightens toward the point where the faces meet, because the decision is all the directions at once. Thin seams in the tile colour separate the faces; at 32px and below the seams drop so the stone stays one clear shape.

Use it for the app icon, favicon and the about screen. It is self-coloured and sits on its own dark tile, so it works on both themes. Without the tile (the website header), the white face turns pale grey (#E3E6EB) on light backgrounds so the outline stays whole. Never recolour the faces, never reorder the band, and never add gloss or highlights: it is flat with one soft light. The product name is a working name, so keep the mark separate from any wordmark; set the name in Inter 600 beside it when needed.
