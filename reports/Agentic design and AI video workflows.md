# Sell the decision layer, not generation

Vellum should build three templates in this order: first an agent-product template, then a template for ads and UGC-style product video, and then, more slowly, a template for independent ex-MBB consultants. In all three it should sell the one thing no competitor records: the directions the person rejected, the test each one could have failed, and a way back to them. Agent products fit best first. The published playbooks (Anthropic, OpenAI, the Husain/Shankar eval method) already describe a gated loop: frame the problem, pick the lowest autonomy that works, run the cheapest proof, judge it against kill criteria set in advance. That loop maps directly onto Gather → Explore → Prototype → Snapshot, and today's only agent-specific templates are static Miro whiteboards and Vercel code starters. In video, vertical micro-drama is the hottest format internationally: AI titles went from **3% to about 67% of new releases outside China between Q1 and Q3 2026**. Ads and UGC product video still make the better first template. A solo operator there sells to a buyer with a budget (**US creator ad spend is forecast at about $44bn for 2026**), meets little AI-policy friction, and gets results back through hook rate, click-through rate (CTR) and cost per acquisition (CPA). A micro-drama pilot-and-trailer template should follow. Consultants already think in Vellum's terms (one-day answer, issue tree, kill the hypothesis, ghost deck) and distrust AI for synthesis: **only 7% always use it**. They will not pay until Wright exports native PowerPoint, though, and large firms would mean years of compliance work against AI seats already held by Claude, ChatGPT Enterprise and Copilot. Two features would make all three templates hard to copy: branching from an earlier point on the board, and a view of all paths with their test results. Neither is built, so both should come before anything else. The main risks are the name clash with Vellum AI (Anthropic's agent guide lists it as an agent framework), Google Stitch, Figma and Miro all moving toward the same agent-plus-canvas-plus-plan-approval product, and fast model churn (OpenAI shut Sora down in 2026).

## Every rival starts at "generate", and none keeps the rejected paths

The competitive picture is the same in all three use cases. Tools either generate or execute. Some now ask for approval before they act. None of them treats *why* a direction was chosen, *what was ruled out* and *which test settled it* as things worth keeping. That gap is the opening Vellum is built to fill. It is also the main reason to build the templates at all: a template is the cheapest way to show a buyer the gap in their own work.

In idea-to-prototype design, Figma now has a generally available on-canvas agent, code layers in open beta, agent chats that teammates can see by default, and Figma Specs, a Markdown design-language document that agents read ([Figma Config 2026 recap](https://www.figma.com/blog/config-2026-recap/); [TechCrunch](https://techcrunch.com/2026/10/14/figma-announces-new-features-to-define-how-agents-work-on-its-platform/)). Google Stitch is the closest to Vellum's idea. It has a design agent that "can reason across the entire project's evolution", an Agent manager that "helps you to work on multiple ideas in parallel", and direct publishing to Netlify ([Google, March 2026](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-ai-ui-design/); [Google, May 2026](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-updates/)). Lovable keeps a version history of plans in `.lovable/plan.md`, but that history **resets after each approve/skip cycle** ([Lovable docs](https://docs.lovable.dev/features/plan-mode)). Figma Make's history is linear: duplicating a file keeps every version, "so you can't fork and start at version 0". In February 2026 users asked for "structured version control / iteration branching for AI workflows" ([Figma forum 50677](https://forum.figma.com/suggest-a-feature-11/figma-make-branching-50677); [Figma forum 51303](https://forum.figma.com/suggest-a-feature-11/figma-make-structured-version-control-iteration-branching-for-ai-workflows-51303)). The only templates aimed at designing *agent products* are static Miro whiteboards, such as the "Multi-Agent System Design Workshop" and the "AI Agent Team Topology Canvas" ([Miro](https://miro.com/templates/multiagent-system-mas-design-workshop/); [Miro](https://miro.com/templates/ai-agent-team-topology-canvas/)), plus code starters from Vercel ([Vercel templates](https://vercel.com/templates/ai/chatbot)). None of them goes on to a prototype and a test.

Video canvases have the same shape. Runway's named workflow templates (Storyboard Creator, Animatic Generator, Style Blend, Virtual Try On) are building blocks for single techniques, not production formats ([Runway Workflows](https://runway.com/workflows)). Krea's Node Agent "proposes a plan you can edit or approve" and shows the compute cost of each node before running, but its docs describe no version history beyond cached outputs ([Krea docs](https://www.krea.ai/docs/user-guide/features/nodes)). Templates built around a format come from linear, agent-led studios instead. TopView Drama Studio and invideo, whose showrunner agent "holds the show bible", record *what* was decided but not what was rejected ([TopView](https://www.topview.ai/en/drama-studio); [invideo](https://invideo.io/blog/showrunner-director-agent-microdrama/)). Only Creatify, which targets media buyers, claims a full loop of generating, launching, measuring and iterating, a claim nobody has verified independently ([Creatify](https://creatify.ai/features/media-buyer)). Consulting splits the same way. Research platforms gather evidence the way Scout does (AlphaSense, estimated at about $700M ARR in June 2026 ([Sacra](https://sacra.com/c/alphasense/))). Slide tools at $10–50 per seat per month produce output the way Wright does ([NOXI comparison](https://noxi.ai/blog/best-ai-presentation-tools-for-consultants)). General chatbots will critique on request, much as the Critic does. No product joins the three in a lasting reasoning structure. The nearest is Mindomo, which attaches a hypothesis, an evidence need and an owner to each branch of a tree, with no AI critique and no decision log ([Mindomo](https://www.mindomo.com/use-cases/idea-organization/issue-trees/)).

| Use case | Strongest incumbents | What they keep | What nobody keeps |
|---|---|---|---|
| Agent-product design | Figma (agent, Make, Specs), Google Stitch, Lovable, Miro | Linear version history, approved plans, agent chat logs | Rejected directions with reasons, a falsifiable test per direction, forking from an earlier version |
| AI video | Flora, Krea, Runway, Figma Weave, Higgsfield, TopView, invideo, Creatify | Generation history, cached outputs, show bibles | Takes rejected and why, goal set before generation, results read back against that goal (outside Creatify's ad loop) |
| Consulting | AlphaSense/Tegus, think-cell Assist, Copilot, Gamma, firm-internal Lilli, Deckster, Sage | Evidence libraries, slide drafts | Killed hypotheses, evidence weight per claim, the reasoning behind the storyline |

Two consequences follow for strategy. First, asking for approval before building is now standard: Lovable Plan mode, Miro Sidekicks that "propose a plan for your approval", Krea's Node Agent ([Miro, May 2026](https://miro.com/blog/whats-new-may-2026/)). Vellum's Keep/Retry/Discard drafts and Accept/Decline proposals are therefore table stakes, not a moat. Second, an AI crew does not set Vellum apart either. invideo already sells producer, storyboard and director-of-photography agents ([invideo](https://invideo.io/blog/ai-micro-drama-script-to-episode/)), and the ad studio Genre.ai has agents pitch "50 different locations" for humans to choose from ([Wrapbook podcast](https://www.wrapbook.com/on-production-podcast/the-real-economics-of-ai-native-production-featuring-pj-accetturo)). What sets Vellum apart is what it remembers, and pricing for solo, local-first use. Flora is "best value for teams", Figma Weave keeps bring-your-own API keys for Enterprise, and Miro AI Workflows launched for enterprise customers ([Flora pricing](https://www.flora.ai/pricing); [Weave pricing](https://weave.figma.com/pricing); [Miro newsroom](https://miro.com/newsroom/miro-launches-ai-workflows/)). The loudest user complaint in both design and video, paying for the AI's mistakes, also favours a tool that decides before it generates. One Figma Make user reported that "40% of credits are to either fix issues created by Make or where it says it's done something and hasn't" ([Figma forum](https://forum.figma.com/share-your-feedback-26/figma-make-ai-credit-limits-not-feasible-51713/index5.html)).

## Agent products: a proof ladder that kills directions cheaply

Agent products should be the first template. The audience is growing, the method is already written down, and Vellum's crew maps onto that method step for step. **About 36% of startups founded on Carta in 2025 had a solo founder, up from 31% in 2024** ([Carta](https://carta.com/data/founder-ownership-2026/)). "Organizations of one" rose from 4% to 10% of Stack Overflow's 2026 respondents ([Stack Overflow](https://stackoverflow.blog/2026/10/06/the-results-of-the-2026-developer-survey-are-here/)). In Figma's 2025 survey, **51% of people working on AI products were building agents, up from 21%** ([Figma AI report 2025](https://figma.com/reports/ai-2025/)). Building has become cheap: Lovable reports about 1M new projects a week ([TechCrunch](https://techcrunch.com/2026/06/09/lovable-says-it-has-hit-500m-in-annualized-revenue-with-1-million-new-projects-a-week/)). The hard part has moved to deciding what to prove and judging the result honestly. Quality is the top barrier to production (32% of organizations), and **29.5% do not evaluate their agents at all** ([LangChain](https://langchain.com/state-of-agent-engineering)). Gartner forecasts that more than 40% of agentic AI projects will be cancelled by the end of 2027, describing most as hype-driven and "often misapplied" ([Gartner](https://www.gartner.com/en/newsroom/press-releases/2025-06-25-gartner-predicts-over-40-percent-of-agentic-ai-projects-will-be-canceled-by-end-of-2027)). Product managers complain that AI prototyping tools "skip the actual product thinking" ([Product Hunt](https://www.producthunt.com/p/vibecoding/anyone-else-finding-ai-design-tools-skip-the-actual-product-thinking)). Supplying that product thinking is Vellum's job.

The method is consistent across sources. Anthropic advises adding "multi-step agentic systems only when simpler solutions fall short" and warns of "compounding errors" ([Anthropic](https://www.anthropic.com/engineering/building-effective-agents)). OpenAI says to start with one agent, validate with real users and keep humans in the loop while the evaluation cycle is built ([OpenAI guide](https://cdn.openai.com/business-guides-and-resources/a-practical-guide-to-building-agents.pdf)). A University of Washington framework sets out five autonomy levels, from L1 Operator (the user decides, the agent acts) to L5 Observer (full autonomy) ([arXiv 2506.12469](https://arxiv.org/abs/2506.12469)). Practitioners stay near the low end: **63% rarely or never let agents run on autopilot, and 69% run a single agent** ([Stack Overflow pulse survey](https://stackoverflow.blog/2026/05/27/agents-on-a-leash-agentic-ai-remains-mostly-monitored-at-work)). Husain and Shankar's eval method starts with "error discovery" on real traces, because "it doesn't make sense to measure everything" ([Lenny's Newsletter](https://lennysnewsletter.com/p/advanced-evals-how-to-find-and-fix)). NN/g recommends Wizard-of-Oz prototypes, where humans fake the hard part, to de-risk generative AI products before building them ([NN/g](https://www.nngroup.com/articles/wizard-of-oz/)). The UX side of agent design has also settled. Autonomy is set per action according to risk, not with one global toggle. In an SAP-led study, 95% of participants wanted humans to confirm critical decisions. High transparency raised the chance an agent was chosen by **+37.8 percentage points**, while a stop button added only **+5.1 points, not statistically significant** ([arXiv 2606.18716](https://arxiv.org/html/2606.18716)). Researchers at Apple and CMU found that node graphs work better for *seeing* how an agent behaves than for *authoring* it ([arXiv 2510.04452](https://arxiv.org/pdf/2510.04452)). That supports a canvas that shows agent decisions instead of making designers program in nodes.

Read together, these sources give a proof ladder ordered by cost, where each rung retires one risk. Problem evidence tests whether the problem is real. A landing page with a pre-sale tests willingness to pay. A Wizard-of-Oz or concierge run, with the founder doing the agent's job by hand, tests whether the output is valued. A clickable prototype of the trust UX (approvals, undo, status) tests whether people are comfortable delegating. A thin working agent run on 20–50 real traced tasks tests whether it is feasible and reliable. Each rung needs a pass/fail threshold set before it runs. Vellum's rule that "real-world evidence comes from the designer, so the crew prepares the test… and the designer runs it" is exactly this discipline (Vellum `stage-role-contract.md`).

### Template 1: idea to validated agent proof

Status key for all three templates. **Built** means the feature exists according to the product brief and the repo's stage contract. **Not built** means it is on the owner's not-yet-built list (branching from an earlier point, the all-paths view with test results, the version browser, the return briefing, sharing and present mode, PowerPoint export, real-time collaboration) or on the repo's own list (Critic objection log, "check back on" dates for tests, medium lenses, stage gates in code). **New** means the template needs a capability that appears on neither list. **Handoff** means the step runs in an outside tool and comes back as cards.

| Stage | Step | Crew, cards and evidence | The person decides | Status |
|---|---|---|---|---|
| Gather | G1. State the job in one sentence | The person drafts the claim (e.g. "solo accountants need an agent that chases missing receipts"). Scout collects forum threads, competing agents and the person's interview notes. First-hand interviews are Observed; articles are Reported; crew summaries are Proposal. | Keep the claim once enough Observed pain sits under it | Built |
| Gather | G2. Is an agent warranted? | Critic tests the claim against "single model call, fixed workflow or agent" and names the riskiest assumption | Keep, reword, or stop: "no agent needed" counts as a result | Built; logging the Critic's objection and the person's override is not built |
| Explore | E1. Fork into directions A–D | Strategist drafts four direction cards that differ in autonomy level, tool scope and approval points. For example: A, a concierge service the founder delivers by hand; B, an L1 copilot that drafts and waits; C, an L3 agent with an intent preview; D, a narrower vertical. Each carries a test it could fail and a threshold set in advance (e.g. "3 of 5 Wizard-of-Oz users accept the draft without edits") | Which directions deserve a test | Built |
| Explore | E2. Critic's four checks | For each direction: agent or workflow; risk × reversibility for each action, which sets the approval point and undo window; whether it combines the "lethal trifecta" or touches production; the 3–5 failure modes to measure | Accept or override each objection | Built (critique); objection log not built |
| Explore | E3. Adopt one direction | The person adopts one direction. The others go to decision memory with reasons and are not proposed again | Adopt | Built |
| Prototype | P1. Demand proof | Wright builds a landing page with a waitlist or pre-sale. The crew drafts the outreach and the person runs it. Critic flags any form that stores personal data | Pre-sale or sign-up threshold met? | Page built; "check back on" date not built |
| Prototype | P2. Wizard-of-Oz or concierge run | Wright builds the front end; the founder does the agent's work by hand for 3–10 users; each session becomes an Observed card | Do users come back for the output? | Built |
| Prototype | P3. Trust-UX prototype | Wright builds a clickable page with the intent preview, approval points, undo window and status states; five-user test | Acceptance and override rates against the threshold | Built |
| Prototype | P4. Thin working agent | Built at L1–L3 in Claude Code, Lovable or an agent SDK; 20–50 real tasks traced; binary pass/fail evals per failure mode, with results imported onto the direction card | Pass rate against the bar set in E1 | Handoff; importing evals and traces is New |
| Prototype | P5. Failed rung → go back | Return to the Explore point where the failing direction was adopted and fork a sibling, with the failed path still visible | Which earlier direction to revive | Not built (branch from an earlier point; all-paths view) |
| Snapshot | S1. Freeze the proof | Snapshot #n freezes the proof that passed, together with its test results and the decisions behind it | What the snapshot does not cover | Built |
| Snapshot | S2. Show it | Share or present to a co-founder, investor or pilot users | Who sees it | Not built |
| Snapshot | S3. Come back | Return briefing: which tests reported, which traces failed, which decisions are pending; real-user traces flow back into Gather as Observed evidence for the next loop | Next test or next build | Not built |

Three design choices make this template work. First, the Critic's four checks should be a fixed checklist, not free-form critique. They come straight from the sources: Anthropic's workflow-versus-agent test; per-action autonomy taken from Smashing Magazine's "autonomy dial" and intent-preview patterns ([Smashing Magazine](https://smashingmagazine.com/2026/02/designing-agentic-ai-practical-ux-patterns/)); Simon Willison's warning that an agent combining private data, untrusted content and outbound communication can be hijacked ([Simon Willison](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/)); and error discovery. Second, default tests can borrow Smashing's proposed thresholds: plan acceptance above 85%, a review if overrides pass 10%, automation switched off if more than 5% of actions are reverted. These are one author's proposals, not industry benchmarks, and the template should label them as Proposal. Third, designers need a variant whose Prototype stage yields the artifacts agent design now runs on: an action-by-risk autonomy matrix, a failure-mode register, a status and interrupt spec, a prompt spec, and an eval kit with a two-axis rubric. Figma scores AI output 1–4 on design and 1–4 on functionality, and argues that "the most important thing is humans, with taste, doing the evals" ([First Round Review](https://review.firstround.com/figma-ai-eval-process/); [Microsoft Fluent 2](https://fluent2.microsoft.design/content-engineering/evaluating-output-quality/)). The template should also treat security as a gate. Cybernews found **24,664 of 34,545 Supabase-backed Lovable projects returning records without authentication** ([Cybernews](https://cybernews.com/security/lovable-ai-apps-expose-personal-information/)). Replit's agent deleted a production database during a code freeze ([The Register](https://www.theregister.com/2025/07/21/replit_saastr_vibe_coding_incident)). A reasonable timeline (an inference from the notes, not a measurement) is days to a first proof and two to six weeks to first real users, with distribution and validation setting the pace rather than build time.

The competitive window is real but short. Stitch already offers parallel directions and an agent that reads project history, free, and Figma is combining Specs, agent and Make. Neither documents rejected options, falsifiable tests or evidence weights. Anthropic's design lead says "we haven't invented an interface for managing hundreds or thousands of Claude instances" ([IDEO](https://www.ideo.com/journal/crafting-the-last-mile-of-delight)), so a named multi-agent crew is an open design space. It is also untested: the only guidance on multi-agent role UI is opinion.

## Video: micro-drama is hottest, but ads pay a solo operator first

The two parts of the question have different answers. If "hottest" means momentum, **vertical micro-drama** wins clearly. Media Partners Asia (MPA) puts global micro-drama revenue at **$20bn in 2026 (+24%)**. Dedicated apps outside China take **$4.87bn, up about one-third** ([Advanced Television, citing MPA](https://www.advanced-television.com/2026/11/26/report-micro-drama-revenue-at-20bn-in-2026/)). Owl & Co counted AI titles at **3%, 28% and about 67%** of releases outside China across Q1, Q2 and Q3 2026 ([Vertical Charts](https://verticalcharts.com/ai-generated-vs-live-action-micro-dramas-reelshort-vertical-52-data/)). YouTube says micro-dramas passed 6.5B views in the first half of 2026 ([YouTube](https://blog.youtube/culture-and-trends/the-evolution-of-web-series-on-youtube-microdramas/)). The weaknesses are just as clear. US revenue is forecast **down 2%**. Four China-owned or China-financed groups hold **65% of revenue outside China**. Platforms spend **56 cents of every revenue dollar on marketing**, and DramaBox ran a **3.2% net margin** in FY2025 (all [MPA](https://www.advanced-television.com/2026/11/26/report-micro-drama-revenue-at-20bn-in-2026/)). In Q1 2026, downloads outside China grew 140% while revenue grew 20% ([adjoe, citing Sensor Tower](https://adjoe.io/blog/short-drama-apps-rewarded-engagement/)). On ReelShort, live-action titles were more likely than AI titles to reach the top 10% by views 30 days after release ([Vertical Charts](https://verticalcharts.com/ai-generated-vs-live-action-micro-dramas-reelshort-vertical-52-data/)). No public revenue-share programme for independent creators was found at the major apps. ReelShort's content chief says AI has "no place" in her writers' room ([Yahoo/Variety](https://www.yahoo.com/entertainment/tv/articles/vertical-micro-dramas-8-billion-130000807.html)).

If the question is where a one-person company can earn repeatedly, **ads and UGC-style product video** win. IAB puts US creator ad spend at **$37bn in 2025 (+26%, about four times the growth of total media)**, rising to about $44bn in 2026, with **48% of buyers calling creators a "must buy"** ([IAB](https://www.iab.com/news/creator-economy-ad-spend-to-reach-37-billion-in-2025-growing-4x-faster-than-total-media-industry-according-to-iab/)). Paid amplification of creator content is expected to grow **48% to $13.2bn** ([Digiday](https://digiday.com/marketing/in-graphic-detail-heres-what-the-creator-economy-is-expected-to-look-like-in-2026/)). Arcads, an eight-person AI-UGC tool, reports about $10M ARR from 6,000+ mostly DTC customers, a self-reported figure ([D2C Times](https://d2c-times.com/arcads-vs-creatify-in-2026-the-ai-video-ad-war-dtc-cant-ignore/)). Vendors put an AI UGC ad at roughly $75–125 all-in, against **$150–300 for a human creator** plus usage rights ([invideo](https://invideo.io/blog/ai-ugc-ad-cost/); [invideo](https://invideo.io/blog/ai-ugc-ads-vs-hiring-creators/)). Meta requires AI disclosure only for social-issue, electoral and political ads ([Digital Applied](https://www.digitalapplied.com/blog/ai-content-labeling-rules-advertisers-2026-reference)). The format also closes its own loop, because every launch returns hook rate, CTR and CPA. The other formats fall short. Shorts pay about **$0.02–0.10 per 1,000 views** ([vidIQ](https://vidiq.com/blog/post/youtube-shorts-monetization/)). Faceless long-form YouTube monetizes, but YouTube bars "AI-generated content made with generic or unoriginal templates giving the impression of mass production" ([YouTube Help](https://support.google.com/youtube/answer/1311392)) and clarified those rules again in July 2026 ([TechCrunch](https://techcrunch.com/2026/07/20/youtube-clarifies-policies-around-ai-slop-and-upsetting-videos/)). No international market data was found for AI music videos or TV-style series.

### Template 2: ads and UGC product-video loop

The template serves two users: a one-person company making ads for its own product, and a freelance creator selling AI ad creative to DTC brands. The second user's value lies in strategy, hooks and testing, not footage. Vellum's local ComfyUI path is economically sound for product shots and B-roll. LTX-2.5 open weights are free for commercial use by organizations under $10M in revenue and have day-zero ComfyUI support ([Comfy blog](https://blog.comfy.org/p/ltx-25-day-0-support-in-comfyui); [LTX](https://ltx.io/blog/ai-video-generation-cost)). Talking-head and lip-synced shots, which UGC ads depend on, currently go to Veo or Seedance ([MinionArts](https://www.minionarts.com/blogs/how-to-make-ai-microdrama-2026-production-playbook)). MiniMax's promise of open weights for H3 is unverified, so Vellum's MiniMax path may end up as an API call rather than a local model ([NYU Shanghai RITS](https://rits.shanghai.nyu.edu/ai/minimax-releases-h3-2k-video-with-native-audio-open-weights-promised/)). The template therefore has to route shots to cloud models or AI-actor tools.

| Stage | Step | Crew, cards and evidence | The person decides | Status |
|---|---|---|---|---|

Scout collects the product page, customer reviews (Reported customer language), competitor ads and past account results (Observed) | Keep the brief | Built; a video "medium lens" is not built |
| Gather | G2. Constraints | Platform specs (9:16, 1080×1920, 6–30 s), disclosure rules by platform and region, music licence, no real faces or third-party IP | Keep the constraints | Built as cards; compliance checklist content is New |
| Explore | E1. Angles A–D | Strategist forks the brief into angle directions (problem–solution testimonial, product demo, founder story, objection or comparison), each with 3–5 hooks and a test it could fail, written before any generation (e.g. "beats account median CTR on a fixed test spend") | Which angles to test | Built |
| Explore | E2. Critic pass | Claims without backing; templated sameness that platform originality rules penalize; likeness and IP | Accept or override | Built |
| Explore | E3. Cost per direction | Shots × seconds × attempts × price, plus 30%, shown per direction; local runs show zero marginal cost | Adopt 1–2 angles within budget | Cost meter is New |
| Prototype | P1. Script and shot list | Wright drafts the script and 4–8 shots; the person edits | Keep the script | Built |

Keep/Retry/Discard per take, and every take is stamped with prompt, seed, model version, references, cost and file | Keep takes | Local generation and drafts built; cloud video routing and take provenance are New |
| Prototype | P4. Cut variants | Assemble in CapCut, Premiere or Resolve; import the renders as cards linked to the angle and hook that produced them | Approve variants | Handoff |

| Snapshot | S2. Launch and wait | The person launches in Meta or TikTok Ads Manager; each test gets a "check back on" date | When to read results | Handoff; date not built |
| Snapshot | S3. Read results | Performance CSV imported as result cards on the directions that produced each variant; the all-paths view shows which angle passed its test | Scale, kill or iterate | Results import is New; all-paths view not built |
| Snapshot | S4. Branch | The winning angle forks new hooks; a discarded angle can be revived from its Explore point; the return briefing summarises the round | Next round | Not built (branching; return briefing) |

The template's economics come from a finding repeated across video sources: cost per finished minute depends on **attempts per usable shot** more than on the per-second price. LTX puts compute for a finished minute at roughly **$20–60 because "each usable shot takes 3 to 10 attempts"**, and tells creators to budget "from shots, seconds and attempts, then add 30%" ([LTX](https://ltx.io/blog/ai-video-generation-cost)). Approving stills before spending video credits is standard advice ([invideo](https://invideo.io/blog/ai-ugc-ads/); [Higgsfield](https://higgsfield.ai/blog/how-to-make-ai-ugc-videos)). Version tracking is still done by hand: creators are told to log "prompt, model + version, settings, seed" in a spreadsheet and keep the rendered file, because "a silent model update quietly breaks old seeds" ([Versely](https://www.versely.studio/blog/ai-video-seeds-and-reproducibility)). Automatic take provenance replaces that spreadsheet. A test written before generation is what cuts attempts. A Product Hunt founder sums up the field: "most AI filmmaking problems aren't really generation problems anymore—they're workflow problems" ([Product Hunt](https://www.producthunt.com/p/ciaro-pro/a-thought-after-launching-ciaro-pro-is-the-auto-filmmaker-idea-fundamentally-wrong)).

### The second format: a micro-drama pilot and trailer, not a season

The next template should be a **micro-drama pilot (one to three episodes) plus a trailer or promo cut**, made to pitch platforms or to self-publish on YouTube or TikTok, rather than a 60–100-episode season. Production guides agree on three gates that must be locked before video credits are spent. The first is the season beat sheet: generating before it is locked is "the single most expensive mistake". The second is the character and world bible, with 6–10 reference images per lead. The third is storyboard stills ([MinionArts](https://www.minionarts.com/blogs/how-to-make-ai-microdrama-2026-production-playbook); [invideo](https://invideo.io/blog/ai-micro-drama-script-to-episode/)). Each gate becomes an Explore decision with lettered alternatives, so branching back is cheap. Holywater publishes the clearest outer loop: it uses AI series on its MyMuse hub to test storylines that it then produces with actors ([Holywater Tech](https://en.wikipedia.org/wiki/Holywater_Tech)). That is Vellum's "test it could fail" applied to a story. The bridge from the first template is commercial. Micro-drama apps put 56 cents of each revenue dollar into marketing, so drama promo cuts are a niche within ad creative, and the ad template extends into them naturally. This template needs three things the first one does not: propagation of changes to locked assets with an impact preview (Genre.ai says changing a locked character means "regenerating every scene that uses it" ([Wrapbook](https://www.wrapbook.com/on-production-podcast/the-real-economics-of-ai-native-production-featuring-pj-accetturo))), retention and continuation data imported per episode, and a story structure locked before production. All three are New.

## Consulting: sell the map behind the deck, to independents first

Vellum should sell to consultants, but third, starting with independents, and only once PowerPoint export exists. The fit with the method is close to exact. *Bulletproof Problem Solving* by Conn and McLean, both ex-McKinsey, describes the habit of asking "What's the one-day answer?" at any point in a project. It describes logic trees that "all started on a sketchpad or a whiteboard", and it tells solo problem solvers to build in review "to get the higher objectivity and other bias-fighting benefits of a team" ([Wiley excerpt](https://catalogimages.wiley.com/images/db/pdf/9781119553021.excerpt.pdf)). Those match the kept claim, the Strategist's directions and the Critic respectively. Ghost decks are built early because "often, what is most apparent from the ghost deck is what is missing" ([Working With McKinsey](https://workingwithmckinsey.blogspot.com/2013/07/McKinsey-presentations-ghost-decks.html)). The documented gap is continuity. The one-day answer must stay current, yet whiteboard trees disappear, and the deck flattens the reasoning: rejected branches and evidence weight vanish on the way to slides. Vendors attack the retyping problem with "whiteboard photo to native slide" features ([Oria](https://www.oria.one/resources/best-ai-presentation-tool-strategy-consultants)). None was found that keeps the reasoning.

Independents are the right first buyers. They decide alone, pay by card and feel the pains Vellum addresses. **Umbrex has 8,500+ members, over 90% of them McKinsey, Bain or BCG alumni** ([StrategyU list](https://strategyu.co/freelance-strategy-consulting-talent-marketplaces/)). Graphite, now part of Toptal, lists 12,000+ vetted independents ([BusinessWire](https://www.businesswire.com/news/home/20260107113891/en)), and McKinsey's alumni network exceeds 70,000 ([McKinsey](https://www.mckinsey.com/alumni/news-and-events/global-news/firm-news/2025-09-meet-the-100000-connections-you-didnt-know-you-had)). MBO counts **5.8M US independents earning $100K+**, nearly double 2020, and full-time independents up **114% since 2020** ([MBO 2026](https://www.prnewswire.com/news-releases/mbo-partners-by-beeline-us-independent-workforce-reaches-record-74-9-million-as-full-time-independence-accelerates-302890957.html)). The core group is plausibly tens of thousands of top-firm-trained independents across the US, UK and Europe. That is an estimate from overlapping network sizes; no reliable count of independent ex-MBB alumni exists. Umbrex's rule of thumb puts a $250K-salary consultant at about **$2,000 a day** ([Umbrex](https://umbrex.com/become-a-consultant/pricing-your-services/)), so $15–40 a month is trivial if the tool saves hours. Their AI use is broad but shallow where it matters. In a survey of 500 UK and European consultants (independents and employees mixed), **only 7% always use AI for synthesis and 69% worry about hallucinations** ([Consultancy.uk](https://www.consultancy.uk/news/39763/just-one-in-ten-consultants-always-using-ai-in-their-work)). Confidentiality is a structural gap for one-person firms. Client contracts increasingly bar client data from AI ([NYU Compliance blog](https://wp.nyu.edu/compliance_enforcement/2025/12/01/ais-biggest-enterprise-challenge-in-2026-contractual-use-limitations-on-data/)). ChatGPT Business, which does not train on data, needs **at least two seats** ([OpenAI Help](https://help.openai.com/en/articles/8792828-chatgpt-business-overview)). Anthropic made training the default on consumer Claude plans, with an opt-out ([Anthropic](https://anthropic.com/news/updates-to-our-consumer-terms)). Catalant's community reports peers "moving to secure environments and local models" ([Catalant](https://catalant.com/digital-and-ai/how-genai-is-reshaping-the-industry-and-empowering-independent-consultants/)). That makes a local-first board with a local model a credible answer. Whether it is a reason to *buy*, rather than just a reason not to reject, is unproven and should be the first question in customer interviews. The reach channels are communities, not ads: Umbrex and its *Unleashed* podcast, Consulting Success, alumni networks and LinkedIn. The likely first verticals are those where data-ban clauses are strictest: financial services, healthcare, private-equity due diligence and the public sector.

The product needs four things to be sellable. **Native, editable PowerPoint export in the client's or firm's template**, with action titles and think-cell-compatible charts, decides the sale. The deck is the unit of value: think-cell's AI tiers reach $1,171 a year ([think-cell](https://www.thinkcell.com/en/pricing)), and Miro's lack of native PowerPoint export is sold against by rivals ([Presentations.ai](https://www.presentations.ai/blog/miro-alternatives)). The second need is consultant vocabulary in the template: one-day answer, hypotheses, kill test, ghost deck, workplan. The third is a present mode, plus a return briefing for the daily rhythm of a case. The fourth is an exportable audit trail positioned as **proof of human judgment**. Source Global Research found that **70% of client companies would not trust a report produced with AI** ([Resultsense, citing The Telegraph](https://www.resultsense.com/news/2026-08-04-consultancy-clients-distrust-ai-reports/)). Deloitte Australia refunded part of a government report after fabricated citations were found ([Fortune](https://fortune.com/2025/10/07/deloitte-ai-australia-government-report-hallucinations-technology-290000-refund/)). Clients are also moving toward shorter cycles, live problem-solving and co-creation rather than long reports ([CMI](https://www.managers.org.uk/knowledge-and-insights/article/top-trends-for-independent-consultants-in-2026)), which favours a live board shown in the room. Independents rank selling and landing projects as their biggest pain, so a proposal variant of the same template, turning the issue tree into a day-one point of view for a pitch, ties Vellum to the pain they feel most.

| Segment | How they buy | What Vellum must have | Price anchor | When |
|---|---|---|---|---|
| Independents, incl. ex-MBB | Alone, by card, through community word of mouth | PowerPoint export, local model mode, present mode, return briefing | ~$15–40/month (inference from think-cell, ChatGPT, Miro anchors) | First consulting launch |
| Boutiques (5–200 people) | Partner decides; a short approved-tools policy ([example policy](https://www.consultancygrowthnetwork.com/ai-policy/)) | All of the above plus firm templates, sharing through firm-controlled storage, bring-your-own approved model | $20–50/seat/month; $75–150 only with collaboration and audit-trail export | After sharing ships |
| Large firms (MBB, Big Four, Accenture) | Procurement and security review | SOC 2 Type II, ISO 27001 (ISO 42001 likely), SSO/SCIM, DPA with no-training terms, EU residency; for a desktop build, code signing, MDM deployment, telemetry control, SBOM, the firm's own model endpoint | Pilot inside a practice | Years out, if at all |

Large firms are not a near-term market. The AI seat is taken: Claude went to about **470,000 Deloitte people** and **276,000+ at KPMG** ([Anthropic](https://www.anthropic.com/news/deloitte-anthropic-partnership); [KPMG](https://kpmg.com/xx/en/media/press-releases/2026/05/kpmg-and-anthropic-sign-global-alliance-and-launch-digital-gateway-powered-by-claude.html)), and client data goes only into approved enterprise tools. The March 2026 breach of McKinsey's Lilli, in which an autonomous agent got read and write access in about two hours, will make reviewers stricter ([The Decoder](https://the-decoder.com/an-ai-agent-hacked-mckinseys-internal-ai-platform-in-two-hours-using-a-decades-old-technique/)). Getting through a cloud review takes the full SOC 2 and ISO list ([Rework](https://resources.rework.com/guides/saas-buying-framework/soc2-iso27001-gdpr-for-buyers)), which is roughly 6–12 months of compliance work before a first enterprise deal (an estimate, not a sourced figure). Vellum's realistic route in is local-first plus the firm's own approved model endpoint, which adds no new data processor. One key unknown: no source says whether firms allow local LLMs on firm laptops. There is also a side door. McKinsey now asks some graduate candidates to work with Lilli in final-round exercises ([HR Grapevine](https://www.hrgrapevine.com/us/content/article/2026-01-15-mckinsey-goes-all-in-on-ai-with-interview-testing-workforce-of-20000-agents)), which makes structured, AI-assisted problem solving a skill people train for.

## Branching and an all-paths view unlock all three templates

Line the three templates up and the build order follows. Two unbuilt features appear in every loop and carry the differentiation: **branching from an earlier point** and **an all-paths view with test results**. In the agent template they revive a sibling direction when a proof fails. In the ad template they show which angle beat its test and bring back a discarded one. In the consulting template they reopen the issue tree when a hypothesis dies. These are the features users explicitly asked Figma Make for, and the Shape of AI pattern library lists "Branches" ("a visible path back to the original") among its "Governors", the patterns that keep a human in control of the AI ([Shape of AI](https://www.shapeof.ai/)). Without them, Vellum's decision memory is a log. With them, it is a map you can work in.

| Capability | Agent template | Ads template | Consulting template | Priority |
|---|---|---|---|---|
| Branch from an earlier point (not built) | Revive a sibling direction after a failed rung | Revive a discarded angle | Reopen the tree when a hypothesis dies | 1 |
| All-paths view with test results (not built) | Proof-ladder scoreboard | Angle scoreboard on CTR or CPA | Hypotheses alive and killed | 1 |

| PowerPoint export (not built) | Investor deck, nice to have | — | Decides the sale | 3; gates the consulting launch |
| Take provenance and per-direction cost meter (New) | — | Core | — | 3; gates the video launch |
| Sharing and present mode (not built) | Investors, pilot users | Client approval for freelancers | Client sessions | 4 |
| Version browser (not built) | Compare proof editions | Compare ad sets | Compare steering-committee editions | 5 |

Each template should ship as a starter board, not a wizard. It would contain the four stage regions; a claim prompt written for the domain; a Strategist recipe for directions, such as autonomy levels, ad angles or hypotheses; a Critic checklist; Wright proof types; and default tests labelled as Proposal until the person edits them. The repo's own unbuilt "medium lenses" (game, video, service) are the natural switch between templates, chosen from the person's own words rather than by matching keywords (Vellum `stage-role-contract.md`). Model names and prices should be data the template reads, not hard-coded steps, for reasons the next section makes plain.

## The name clash, platform convergence and model churn are the top risks

The most immediate risk is the name. Anthropic's "Building effective agents", the standard reference for exactly the audience the first template targets, lists **Vellum** next to the Claude Agent SDK, Strands Agents SDK and Rivet as an agent framework ([Anthropic](https://www.anthropic.com/engineering/building-effective-agents)). Vellum AI (vellum.ai) is an established platform for building agents and LLM apps. A local-first "Vellum" selling an agent-product template will collide with it in search, in the minds of developers and founders, and possibly in trademark review. The notes contain no trademark analysis. Clearance in the target markets, and a decision on a qualifier or a rename, should come before the agent template is marketed.

The second risk is convergence. Stitch, Figma, Miro and Krea are all adding agents that plan and wait for approval, show parallel variants and link canvases to coding tools through MCP. Miro's canvas can already be read and written by outside agents, and Miro is a native connector in ChatGPT, Claude and Copilot ([Miro newsroom](https://miro.com/newsroom/miro-takes-aim-at-the-gap-between-ai-potential-and-organizational-reality)). Frontier vendors deployed inside firms, such as KPMG's Claude-powered Digital Gateway, could add "thinking" canvases inside the tenancy that is already approved. Vellum's defence is narrow but real: rejected options with reasons, falsifiable tests, evidence weights, local-first ownership and pricing for one person. None of the incumbents documents any of these today. The defence holds only if branching and the all-paths view ship before Stitch adds rationale to its Agent manager.

The third risk is churn in the video model layer. OpenAI announced the end of Sora on 2026-03-24 and shut its API on 2026-09-24 ([TechCrunch](https://techcrunch.com/2026/03/24/openais-sora-was-the-creepiest-app-on-your-phone-now-its-shutting-down/)). One third-party page says Veo 3.1 Fast and Quality leave Flow on 2026-12-05 (unverified). Take provenance that stores the rendered file is the only version history that survives a model being retired. Rights add a further layer of risk. Disney sent ByteDance a cease-and-desist over Seedance 2.0 ([Axios](https://www.axios.com/2026/02/13/disney-bytedance-seedance)). Suno now "technically retains authorship" of songs and licenses only songs made while subscribed ([Music in Africa](https://www.musicinafrica.net/magazine/suno-adjusts-ai-music-ownership-terms-after-warner-music-partnership)). EU AI Act Article 50 labelling duties took effect on 2026-08-02 ([Orrick](https://www.orrick.com/en/Insights/2026/08/EU-AI-Act-Transparency-Obligations-for-AI-Generated-Content-Article-50)). TikTok automatically labels uploads that carry C2PA credentials ([TikTok](https://support.tiktok.com/en/using-tiktok/creating-videos/ai-generated-content)). The rules work in Vellum's favour, though. Platforms penalize templated mass production, not AI as such, and the US Copyright Office says human "meaningful selection and arrangement" of AI outputs can be protected ([Copyright Office](https://blogs.loc.gov/copyright/2025/02/inside-the-copyright-offices-report-copyright-and-artificial-intelligence-part-2-copyrightability/)). A record of human decisions is evidence for both. Whether a Vellum trail would satisfy a monetization reviewer or a copyright examiner is an untested hypothesis. Local generation has its own limits. LTX says its model needs 32GB+ of VRAM, while community guides claim quantized builds run in 8–16GB ([LTX](https://ltx.io/blog/ai-video-generation-cost); [DEV Community](https://dev.to/gary_yan_86eb77d35e0070f5/how-to-configure-ltx-2-in-comfyui-complete-2026-guide-for-ai-video-generation-32lk)), so the hardware floor for local-only ad production is unclear.

The last group of risks is about evidence. Willingness to pay for planning separately from generation credits is unproven in video. Local-first as a reason for consultants to buy is unproven. Most video cost and time figures come from vendors, and micro-drama market sizes conflict between MPA's $20bn and Omdia's $14.1bn for 2026 because the two firms scope the market differently ([Vertical Observer](https://verticalobserver.com/guides/microdrama-statistics/)). Before committing build effort, Vellum should run its own templates on itself. That means about 10–15 interviews each with solo agent founders, freelance ad creators and Umbrex-style independents, with pre-sale tests that each could fail.

## Conclusion

The three use cases are one loop in three costumes: a claim, competing directions with tests that could fail, the cheapest proof, results read back, and a branch back to an earlier choice. That changes what Vellum is selling. The four-member crew is already standard in the market, and the draft-and-approve rhythm is now table stakes. What no one sells is the memory of paths not taken, joined to the results that killed them. So the unbuilt "go back and branch" and "all paths with test results" features are the product itself, and every template launched before them shows off a moat that does not exist yet. Each template also produces a different payoff from the same record of decisions. It is a kill-criteria discipline for agent founders who would otherwise over-build. It is a cost lever for video creators, because the test written before generation cuts attempts per usable shot. For consultants it is a client-facing deliverable, proof that humans did the judging, at a moment when 70% of clients say they distrust AI-made reports.

The second implication is about pace and sequence. Agent products and ads both let a solo user close the loop in days with real-world signals they own: pre-sales, traces, CTR. That makes them the right proving ground for branching and results import. Consulting pays more per user, but it waits on PowerPoint export and confidentiality proof, and it rewards a product that has already shown its decision trail working elsewhere. Micro-drama will keep the headlines. For a one-person company, though, it is a market for pilots and trailers, sold into a concentrated, low-margin buyer base, and should be treated that way, not chased as a season-production business.
