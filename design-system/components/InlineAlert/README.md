A message that belongs to one place on the page: a tinted fill with an icon, a bold lead and one sentence. Never a bordered box.

- `tone`: `info` (default), `warn`, `danger`, `ok`. `danger` is announced as an alert.
- An optional `action` button sits on the right (*Review*, *Retry*).
- For something that just happened, use a `Toast`. For a problem with one card, use `Card state="error"`.
