A focused question that needs an answer before you go on. Use it rarely: prefer a `Sheet`, an inline control or an undo.

- The title is a question in `heading` (*“Delete this board?”*). The body says what happens, and what doesn't.
- Actions are verbs that repeat the outcome (*Keep board* · *Delete board*), never OK/Cancel. A destructive action uses `danger`.
- `scrim` blurs the board behind. Escape and the close button both cancel.
